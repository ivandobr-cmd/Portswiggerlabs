# PortSwigger Web Security Academy — Write-ups

Hi! My name is Ivan, and I am an Information Security Specialist (Penetration Tester / AppSec).

This repository contains my solutions to the PortSwigger Web Security Academy labs. I document only the most interesting and complex cases to showcase my approach to finding and exploiting vulnerabilities.

*   **Total solved:** 66 labs (and counting).
*   **Difficulty levels:** The repository mainly features **Expert** and **Practitioner** level tasks.
*   **Topics:** SQLi, XSS, SSRF, HTTP Request Smuggling, Web Cache Poisoning, Path Traversal, authentication, and access control.

Each `.md` file is a write-up of a single lab. Inside, you will find steps to reproduce and final payload.
